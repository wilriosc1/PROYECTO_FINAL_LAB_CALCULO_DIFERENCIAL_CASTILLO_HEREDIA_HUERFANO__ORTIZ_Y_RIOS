# ¿Cómo se enfría un tinto?

Proyecto final: medición y análisis del enfriamiento de un tinto recién servido.

## Descripción

En este proyecto estudiaremos cómo cambia la temperatura de un tinto desde que se sirve hasta que llega a una temperatura que el equipo considera adecuada para tomarlo. Tomaremos datos propios con un termómetro de cocina y un cronómetro, y repetiremos el experimento al menos dos veces para comparar los resultados.

## Pregunta de investigación

**¿Con qué rapidez se enfría un tinto recién servido y en qué minuto llega a la temperatura a la que nos lo tomaríamos?**

## Objetivos

- Registrar la temperatura del tinto a medida que transcurre el tiempo.
- Comparar al menos dos ensayos realizados bajo condiciones similares.
- Estimar el tiempo necesario para alcanzar la temperatura de consumo elegida.
- Describir qué factores pueden influir en el enfriamiento.

## Materiales

- Tinto recién preparado.
- Termómetro de cocina.
- Cronómetro (puede ser el de un teléfono).
- Recipiente para servir el tinto.
- Hoja de cálculo o cuaderno para registrar las mediciones.
